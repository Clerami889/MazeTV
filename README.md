1.How to run
- clone the repo
- open the project in android studio
- let gradle sync
- run the app on an emulator or a physical device with android 8+

or 

- download the apk/aab
- install it
- open the app

2.My Architecture decision
- i use MVVM since its the most well known and one ive had the most experience about cause ive been using mvvm since Bangkit and quite verse with them
- use Repository for abstraction
- Dependency injection with Hilt all of my course always use hilt to help with DI and with this my knowledge with Hilt is great and there is also the hilt-navigation-compose dependencies that allows hilt to automatically inject viewmodel to the screen
- UIState separated and sealed for reusability and consistency
- i always try to use the best practice in every part of my code to ensure im building the correct habits
